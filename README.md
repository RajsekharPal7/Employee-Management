# Employee Management (Python + SQLite)

A simple command-line CRUD app using Python and SQLite.

## Setup

Run all commands from the project root.

```bash
python create_table.py
```

## Usage

```bash
python insert.py   # Add an employee
python read.py     # View all employees
python update.py   # Update salary by ID
python delete.py   # Delete employee by ID
```

## Tech

- Python 3
- sqlite3 (built-in)
